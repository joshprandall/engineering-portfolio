What it is

Learn from distances, directions, symmetries, manifolds, and transformations instead of treating every input coordinate as unrelated.

This page separates the concept, implementation path, interactive experiment, evaluation criteria, failure modes, and sources so the topic can be studied without relying on a summary tile.

Core concepts

  • Invariance: a prediction should remain unchanged under a transformation that does not change the task.
  • Equivariance: internal representations should transform in a predictable way when the input transforms.
  • Geometry-aware representations: distances, angles, neighborhoods, manifolds, groups, and graphs encode structure that ordinary flat vectors may hide.
  • Inductive bias: architecture can build known structure into the model rather than forcing data alone to rediscover it.

Architecture / workflow

  1. Identify the transformations that should preserve or predictably change the target.
  2. Choose a representation that preserves the relevant geometry.
  3. Apply an invariant or equivariant operation, message-passing rule, kernel, or architecture.
  4. Train against the task objective while testing transformed and out-of-distribution inputs.
  5. Evaluate whether the model keeps the promised geometric behavior outside the training examples.

Technical foundations

  • Euclidean distance: d(x,y)=√Σᵢ(xᵢ−yᵢ)².
  • A transformation T is invariant for f when f(Tx)=f(x).
  • A representation is equivariant when f(Tx)=T′f(x) for the corresponding output transformation T′.
  • Graph and manifold methods replace a single global coordinate grid with local neighborhoods and structured relations.

Evaluation checklist

  • Test rotated, translated, permuted, or otherwise transformed inputs.
  • Measure ordinary task error and symmetry-consistency error separately.
  • Include out-of-distribution geometries rather than only random train/test splits.
  • Compare against a non-geometric baseline to verify the added inductive bias actually helps.

Failure modes and limits

  • Encoding the wrong symmetry can systematically erase useful information.
  • Geometric structure does not provide semantics by itself.
  • Numerical approximations and neighborhood construction can break theoretical invariances.
  • A benchmark may accidentally share geometric patterns between train and test sets.

Practical build path

  1. Start with nearest-neighbor distances and rotation tests on a small synthetic dataset.
  2. Add an invariant feature baseline and compare it with raw-coordinate learning.
  3. Implement an equivariant or message-passing model and measure transformation consistency.
  4. Profile accuracy, compute cost, generalization, and failure cases on unseen geometries.

AUTHORED STUDY COMPANION / 3.2

Check an equivariant coordinate update

Prerequisites. Distances, rotations, translations and graph message passing.

A distance-based message can remain unchanged when all coordinates rotate or translate together. The companion uses weights exp(−||xᵢ−xⱼ||²) and an update x′ᵢ=xᵢ+0.1Σⱼ(xᵢ−xⱼ)wᵢⱼ. Distances are invariant; displacement vectors rotate; summing weighted displacements therefore produces a coordinate update that rotates and translates with the input.

This is a deliberately small EGNN-style coordinate rule inspired by the paper's architecture, with fixed functions rather than learned networks. Three two-dimensional points are transformed by a rotation and translation, processed, and compared with transforming the original outputs. The residual should be near machine precision. Translation cancels in pairwise differences and reappears through the original coordinate xᵢ.

Equivariance alone does not make a model accurate, stable across many layers, or appropriate for every physical quantity. A task may require conservation laws, reflection-sensitive features or boundary conditions that this update does not encode. A symmetry test should specify the transformation group and the type of each output.

Extend the experiment

Replace the distance weight with the absolute x coordinate of a node. Repeat the translation test and locate the symmetry violation.

Check your reasoning: Which quantity stays unchanged by rotating the whole point set?
  1. Each x coordinate — Individual coordinates depend on the coordinate frame.
  2. Pairwise Euclidean distance — Correct. Rigid rotation preserves Euclidean length.
  3. Each displacement vector component — The vector rotates; its individual components generally change.

This is an explained self-check, not a certification of mastery.
