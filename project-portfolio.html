This site is a responsive static engineering portfolio built with semantic HTML, shared CSS, and plain JavaScript, with accessibility and progressive enhancement treated as design requirements rather than afterthoughts.

Static by design

No application server, database, API key, framework, or runtime dependency is required for the live site. Core content remains available before JavaScript runs.

Accessible interaction

Skip navigation, visible focus, keyboard-operable controls, native dialogs, project filters, reduced-motion support, and semantic landmarks are built into the interface.

Validated behavior

GitHub Actions checks required files, duplicate IDs, local references, skip-link targets, document language, external-link safety, project metadata, and core accessibility hooks.

Published v1.0.0 · Site validation passing · The live version remains hosted through Oregon State University Engineering web hosting.
