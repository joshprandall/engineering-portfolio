Joshua Randall Knowledge Platform v1.1.0 — Deep Learning Edition

Published scale retained from v1.0.0:
- 8,000 learning objects
- 3,000 labs
- 300 guided curricula
- 1,600 glossary concepts
- 4,000 lab/model interactive learning experiences

Every learning object now opens as a multi-page learning experience:
Overview → Explain → Visual → Video → Lab → Practice → Review → Evidence

Audience modes:
- Starter / young learner
- General learner
- Technical depth

Deep-learning expansion is lazy-loaded from the deep-learning/ directory in 76 domain/category chunks so a phone does not need to download every expanded teaching pack at startup.

YouTube policy:
Every lesson has a Video view. A curated foundation video is embedded without autoplay using youtube-nocookie.com. Each lesson also has an exact-topic YouTube search link and a browser-local option to pin a more precise video. YouTube content is supplementary and never counts as verification evidence.

Accuracy policy:
The verified claim ledger and authoritative evidence remain the factual publication gate. Derived labs and practice objects inherit the verified claim and evidence from their parent source lesson. Analogies are labeled as non-literal teaching aids.
