GUIDED PROOF LAB / DISCRETE MATHEMATICS

From examples to a proof: mathematical induction

Try this self-contained proof lab after learning quantifiers, implications, and algebraic identities. You will state the exact domain of a claim, prove a base case, connect an arbitrary case to its successor, and challenge an attractive but false generalization. This is a guided reasoning exercise, not an executable simulator, graded assessment, or claim of independent mastery certification.

Learning outcomes and prerequisites

  • Prerequisites: natural-number indexing, finite sums, factoring, universal quantifiers, and the meaning of implication.
  • Explain: distinguish testing finitely many examples from proving a universal statement.
  • Apply: prove a formula for every positive integer by a valid base and inductive step.
  • Debug: find the missing hypothesis, circular assumption, or domain mismatch in a proof attempt.
  • Verify: check algebra independently and identify exactly what a cited reference teaches.

Worked proof: the sum of the first n odd numbers

Claim. For every integer n ≥ 1, the sum 1 + 3 + 5 + … + (2n − 1) equals n². The quantified domain matters: this proof starts at n = 1, and the final summand is the nth positive odd integer.

  1. Base case P(1). The sum contains one term, 1, which equals 1². So the claim holds at the specified starting index.
  2. Induction hypothesis. Fix an arbitrary integer k ≥ 1. Assume P(k): the sum of the first k odd numbers is k². This is a temporary assumption for proving the implication P(k) ⇒ P(k + 1), not an assumption that the theorem is already true for every k.
  3. Successor step. The next odd number after 2k − 1 is 2k + 1. Thus the first k + 1 terms total k² + (2k + 1), by the induction hypothesis.
  4. Complete the algebra. k² + 2k + 1 = (k + 1)², which is exactly P(k + 1). The transformation is a polynomial identity and does not rely on checking a particular value of k.
  5. Conclude. The base case and implication for every k ≥ 1 establish P(n) for every integer n ≥ 1 by mathematical induction.

Independent numerical checks, not the proof: n = 4 gives 1 + 3 + 5 + 7 = 16; n = 5 adds 9 and gives 25. These checks are useful for catching transcription errors, but no finite set of sample values replaces the inductive argument.

Practice A: identify the failed proof obligation

A proposed proof checks P(1), P(2), …, P(20) and concludes P(n) for every positive integer. Name the missing step. Then examine a second argument that claims “assume P(k + 1); therefore P(k + 1).” Explain the circularity.

Reveal the reasoning check for Practice A

Twenty verified instances do not prove a universally quantified claim over infinitely many positive integers; the proof never establishes P(k) ⇒ P(k + 1) for an arbitrary k. The second argument assumes the desired conclusion rather than deriving it from P(k), so it does not provide the required implication.

Practice B: falsify a persuasive pattern

Someone claims n² + n + 41 is prime for every nonnegative integer n because it works for many small values. Test n = 40, factor the result, and decide whether induction could rescue the original universal claim.

Reveal the arithmetic and verdict for Practice B

At n = 40, the expression is 40² + 40 + 41 = 1681 = 41², which is composite. One valid counterexample falsifies the universal claim. Induction cannot prove a false statement; its hypotheses or claimed domain must change before a different theorem can be considered.

Practice C: choose an appropriate proof method

Prove that n(n + 1) is even for every nonnegative integer n. First give a short direct proof using consecutive integers. Then, optionally, prove the same result with induction. Which proof exposes the underlying reason most clearly?

Reveal a valid direct argument for Practice C

Among any two consecutive integers, one is divisible by 2. Because n and n + 1 are consecutive, their product is divisible by 2, including the case n = 0. A valid inductive proof is also possible; using induction is a choice, not a requirement for every claim about integers.

Practice D: distinguish ordinary and strong induction

Suppose a recurrence for T(n + 1) depends on both T(n) and T(n − 1). Explain why an induction hypothesis containing only one case may be insufficient and describe the stronger hypothesis you would try. State the base cases your proposed recurrence actually needs; do not invent a recurrence that has not been specified.

Reveal the proof-planning guidance for Practice D

When the successor step needs two preceding facts, an induction argument can assume the required earlier cases, usually using strong induction or a strengthened statement. The recurrence and its starting domain determine how many base cases are necessary. Strong induction is not more powerful than ordinary induction as a logical principle; the larger hypothesis can make a particular proof more convenient.

Self-assessment and evidence boundary

Before moving on, write a proof in your own words and check four criteria: the domain is explicit; the base case actually matches the domain; the inductive step starts from P(k) and derives P(k + 1); the conclusion quantifies over the intended integers. If one fails, revise the proof rather than treating a sample computation as sufficient evidence.
