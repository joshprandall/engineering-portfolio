What it is

Learn over entities and relationships by repeatedly exchanging and aggregating messages along graph edges.

This page separates the concept, implementation path, interactive experiment, evaluation criteria, failure modes, and sources so the topic can be studied without relying on a summary tile.

Core concepts

  • Nodes represent entities, edges represent relationships, and features describe nodes or edges.
  • Message passing gathers information from neighboring nodes.
  • Aggregation should respect graph permutation symmetry.
  • Depth controls how far information propagates but can also cause oversmoothing.
  • Graph construction is part of the model: the chosen edges determine which information can flow.

Architecture / workflow

  1. Define graph entities, edges, features, and target.
  2. Create train/validation/test splits that prevent graph leakage.
  3. Choose aggregation and update rules.
  4. Train node-, edge-, or graph-level predictions.
  5. Test unseen graph structures and perturb edges to measure sensitivity.

Technical foundations

  • Generic message passing: mᵥ=AGG({M(hᵥ,hᵤ,eᵤᵥ):u∈N(v)}), then h′ᵥ=U(hᵥ,mᵥ).
  • Mean, sum, max, and attention aggregation encode different assumptions.
  • Permutation invariance means node ordering should not change graph-level output.
  • Spectral and spatial graph methods offer different views of graph structure.

Evaluation checklist

  • Compare with non-graph baselines.
  • Use splits that match deployment: unseen nodes, edges, time periods, or whole graphs.
  • Measure sensitivity to missing or noisy edges.
  • Track oversmoothing and representation collapse with depth.

Failure modes and limits

  • Graph leakage can make test nodes indirectly expose training labels.
  • Bad edge definitions can encode the wrong relationships.
  • Deep message passing can make node representations indistinguishable.
  • Large graphs can create memory and sampling bottlenecks.

Practical build path

  1. Implement one-step mean aggregation by hand.
  2. Train a small node classifier.
  3. Compare shallow vs deeper message passing and inspect embeddings.
  4. Evaluate on unseen graph structures and deliberately corrupted edges.
