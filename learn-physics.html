GUIDED LESSON / QUANTUM FOUNDATIONS

Predict a qubit measurement without erasing phase

Prerequisites: complex numbers, squared magnitude, probability. Outcome: calculate a single-qubit Z-basis measurement and name what that result cannot reveal.

For a pure qubit, write |ψ⟩ = cos(θ/2)|0⟩ + eiφsin(θ/2)|1⟩. The Born rule gives P(0) = cos²(θ/2) and P(1) = sin²(θ/2). These add to one. Relative phase φ does not change these two probabilities in a Z-basis measurement, though it can change outcomes after another gate or in another basis.

Worked prediction

Choose θ = π/3 and φ = π/2. Then P(0) = cos²(π/6) = 3/4 and P(1) = 1/4. Over 100 ideal, independent preparations measured once each, the expected counts are 75 and 25. A particular finite run need not produce exactly those counts.

Try it, then check

Set θ = π/2. Compare φ = 0 and φ = π. Predict both Z-basis distributions. Then ask whether the two states are physically indistinguishable in all measurements.

Reveal an explained solution

Both give P(0) = P(1) = 1/2 in the Z basis. They are |+⟩ and |−⟩, respectively, which an X-basis measurement distinguishes ideally. Relative phase is not a global phase.

Common mistake: treating |+⟩ as merely a classical random bit. A random bit with half of each Z outcome lacks the phase relation that produces a definite X-basis outcome.

Limit: this ideal single-qubit model excludes state-preparation error, readout error, decoherence and finite-sample confidence analysis; a hardware experiment must quantify those separately.
