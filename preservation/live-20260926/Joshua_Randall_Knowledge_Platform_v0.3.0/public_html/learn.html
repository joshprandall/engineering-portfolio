08 / LEARNING STANDARD

Built to teach, not to inflate a page count.

01

First principles

New concepts are connected to what the learner already knows, with prerequisites visible rather than hidden.

02

Multiple modalities

Text, diagrams, interactive models, optional narration, sound, examples, and labs reinforce the same idea in different ways.

03

Evidence over theater

Version-sensitive material points learners toward primary documentation. Roadmap topics are clearly labeled as roadmap topics.

04

Accessibility first

Keyboard navigation, reduced motion, silent defaults for nonessential sound, readable contrast, and text equivalents are part of the design.
