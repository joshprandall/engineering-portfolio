WORKING BROWSER LAB / SYNTHETIC MODEL

Inspect the software behavior.

Tokenize a tiny language, build a typed syntax tree and reject invalid programs before execution. The browser model is deterministic and intentionally synthetic so the behavior can be inspected without pretending it is a production deployment.
