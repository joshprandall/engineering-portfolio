10 / EVIDENCE + ACCURACY

Trust should be inspectable.

Every published object exposes its evidence inside the lesson. The verification manifest shipped with this release provides an auditable index of lesson IDs, review status, claim type, and sources.

01

Start with authoritative material

Prefer standards bodies, official project/vendor documentation, NIST/CISA/OWASP guidance, and university/open textbooks appropriate to the subject.

02

Cross-check the lesson claim

The explanation, example, takeaway, and quiz are checked against the cited evidence before the object receives a verified status.

03

Label moving targets

Version-sensitive technologies are explicitly marked. Learners can open the current source rather than treating a dated procedure as timeless.

04

Make proof one click away

Use the Verify this lesson button on any lesson to jump directly to its evidence and official source links.

11 / LEARNING STANDARD

Built to teach, not to inflate a page count.

01

First principles

New concepts are connected to what the learner already knows, with prerequisites visible rather than hidden.

02

Multiple modalities

Text, diagrams, interactive models, optional narration, sound, examples, and labs reinforce the same idea in different ways.

03

Evidence over theater

Version-sensitive material points learners toward primary documentation. Roadmap topics are clearly labeled as roadmap topics.

04

Accessibility first

Keyboard navigation, reduced motion, silent defaults for nonessential sound, readable contrast, and text equivalents are part of the design.
