WORKING BROWSER LAB / SYNTHETIC MODEL

Inspect the software behavior.

Model long-running workflows with immutable events, explicit state transitions, retries, idempotency and deterministic replay. The browser model is deterministic and intentionally synthetic so the behavior can be inspected without pretending it is a production deployment.
