# Evil Wizard source snapshot

This snapshot documents the browser-ready Godot project used by the portfolio page. The full repository remains at [joshprandall/Defeat-the-Evil-Wizard](https://github.com/joshprandall/Defeat-the-Evil-Wizard).

## Current controls

| Action | Desktop | Mobile and tablet |
| --- | --- | --- |
| Move | W / A / S / D or arrow keys | Left virtual stick |
| Jump | E or W | Up action button |
| Crouch | Q | Down action button |
| Attack | Space or left mouse | Sword action button |
| Dash | Shift or X | Dash action button |
| Abilities | L / I | Ability buttons |
| Ultimate | U | Ultimate button |
| Interact | F | Interact button |
| Console | Backquote | Console button |

The touch overlay is landscape-first, uses large square beveled controls for phones and tablets, supports multi-touch, and includes an in-game control console. The included smoke test exercises touch press/release, crouch, attack, and console toggling.
