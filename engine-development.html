Custom Game Engine Development

Own the interfaces. Keep games shipping.

Future architecture

The engine is a planned project, not a replacement for the working Godot export or Crown & Ash runtime.

  1. Platform adapters: windows, input, clocks and filesystem.
  2. Joshua-owned scene, entity, asset and save formats with documented versioning.
  3. Renderer, physics and audio interfaces behind replaceable adapters.
  4. Deterministic simulation, replay and headless tests.
  5. Editor and build pipeline separated from the runtime.

Ownership and commercial use

Keep original engine architecture, source and formats under Joshua’s control. Prefer permissively licensed dependencies after reviewing their actual license and redistribution obligations. Third-party code retains its own ownership and notices; an adapter does not change its license.

Integration gates

Prototype one subsystem, measure performance, verify asset round trips, and test compatibility before a game adopts it. No full engine build is part of this phase.
