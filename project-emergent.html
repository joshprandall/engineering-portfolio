Local rules, collective behavior

This is a Kuramoto phase-oscillator model on a seeded random graph. Every node has an intrinsic frequency; connected nodes influence each other’s phase. The order parameter R ranges from 0 (phases dispersed) to 1 (phases aligned).

This is an educational dynamical-systems experiment. It does not reproduce or validate Vitaly Vanchurin’s proposal that fundamental physics might emerge from a neural network.
