Local rules, collective behavior

This is a Kuramoto phase-oscillator model on a seeded random graph. Every node has an intrinsic frequency; connected nodes influence each other’s phase. The order parameter R ranges from 0 (phases dispersed) to 1 (phases aligned).

This is an educational dynamical-systems experiment. It does not reproduce or validate Vitaly Vanchurin’s proposal that fundamental physics might emerge from a neural network.

AUTHORED STUDY COMPANION / 3.4

Check synchronization against numerical resolution

Prerequisites. Ordinary differential equations, graphs, phases and numerical integration.

The model evolves phase θᵢ with intrinsic frequency ωᵢ and degree-normalized coupling KΣⱼAᵢⱼsin(θⱼ−θᵢ)/max(1,dᵢ). The order parameter R=|N⁻¹Σᵢexp(iθᵢ)| lies between zero and one and measures instantaneous phase concentration. It is not a measure of intelligence, a physical universe, or proof that every oscillator is frequency-locked.

The companion creates a fixed seeded random graph, frequencies and initial phases, then runs explicit Euler integration to the same final time with steps Δt and Δt/2. It compares phases using wrapped differences and reports both R values. Holding the graph and initial condition fixed isolates discretization effects; changing the random seed at the same time would confound that comparison.

One refinement comparison is a diagnostic rather than a convergence proof. Repeat another halving and then an ensemble of seeds before claiming a stable regime. The companion's NumPy random stream differs from the browser's seeded generator, so matching seed numbers alone does not imply identical graphs. The existing browser model and its animation remain unchanged.

Extend the experiment

Run ten seeds at several coupling strengths. Report the seed distribution and a time-step refinement check instead of selecting the most coherent animation.

Check your reasoning: Which change isolates time-discretization error?
  1. Change seed and time step together — That mixes two sources of variation.
  2. Hold the fixture fixed and halve the time step — Correct. The comparison controls graph and initial conditions.
  3. Choose only the largest observed R — Selection by the desired outcome biases the report.

This is an explained self-check, not a certification of mastery.

Problem, implementation and evidence

A coherent-looking animation can conceal time-step or seed effects.

The existing seeded oscillator model is paired with a separate fixed-fixture Euler refinement comparison and an ensemble extension task.

What the evidence establishes

Deterministic browser simulation plus executed CPU convergence fixture. No claim that the model reproduces fundamental physics or a physical universe.

Reproduce or extend

Hold initial conditions fixed for time-step checks, then compare multiple seeds at each coupling strength.
